Drop your image files in this folder using these exact names and they'll
appear on the site automatically (no code changes needed):

  profile.jpg     - hero photo next to "whoami" on the Summary section (square, 300px+)
  qu-cricket.jpg  - Outside section, cricket photo (roughly 4:3, 800x600px+)
  speaking.jpg    - Outside section, speaking/teaching photo (roughly 4:3, 800x600px+)

.png or .webp work too - just update the "src" in index.html to match the extension
you used (search for "assets/img/" to find the three <img> tags).

If a file isn't here yet, the site shows a plain placeholder tile instead of a
broken-image icon, so it's safe to deploy before you've added real photos.
